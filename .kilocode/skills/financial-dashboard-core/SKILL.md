# 财务数据大盘核心指标

本技能提供财务数据大盘核心指标的查询和分析能力，面向 E2C Energy 公司内部员工和管理层。

## 核心数据范围

- **收入指标**: 今日收入、本月收入、本年收入、环比变化
- **支出指标**: 今日支出、本月支出、本年支出、环比变化
- **利润指标**: 今日净利润、本月净利润、本年净利润、环比变化
- **应收应付(AR/AP)**: 本月应收总额、本月应付总额、环比变化
- **钱包余额**: 当前钱包余额、上月同期对比、环比变化
- **订单利润**: 本月订单营收、订单成本、订单利润、利润率
- **结算汇总**: 本月已结算金额、待结算金额、环比变化
- **今日运营**: 今日开单数、今日订单数、待确认订单数及金额
- **经营指标**: 经营利润率、净现金头寸、现金缺口、采购收入比、毛利率

## 数据来源

- `billing` 表 - 账单数据（收入/支出）
- `billing_lines` 表 - 账单明细
- `order_sales_profit` 表 - 订单利润数据
- `order_amount` 表 - 订单金额（fallback）
- `wallet_account` 表 - 钱包账户
- `settlement` 表 - 结算记录
- `order` 表 - 订单数据

## 口径说明

- 指标维度支持 `create`（创建时间）和 `delivery`（出单时间）两种口径
- 环比变化使用工作日标准化算法（weekdayNormalizedMomChange）
- 缓存策略: 核心指标缓存 5 分钟

## 查询示例

```
查询本月收入
查询本月利润
查询应收应付
查询今日订单数
查询现金缺口
```

## 权限说明

- 员工: 可查看本人相关数据
- 管理层: 可查看全公司数据
- 财务: 可查看详细财务数据
