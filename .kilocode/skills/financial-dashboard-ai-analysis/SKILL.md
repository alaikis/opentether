# 财务数据大盘 AI 智能分析

本技能基于财务数据大盘核心数据，通过 AI 生成董事会级别的企业经营分析报告。

## 报告章节

1. **经营结论** - 3-5条最关键的经营结论
2. **核心经营记分卡** - 收入、支出、利润、利润率、现金缺口、PMI、SMI
3. **收入与增长来源分析** - 销售渠道、市场、员工表现，识别Top3增长驱动和2个下滑领域
4. **盈利能力与毛利质量分析** - 毛利率、经营利润率、成本结构
5. **现金流与营运资金诊断** - 应收应付、钱包余额、结算、现金缺口
6. **订单健康与运营风险** - 订单状态分布、待确认订单、履约率
7. **采-存-售经营闭环分析** - 采购待处理、库存价值、库销比、成本流向
8. **多仓履约与配送表现** - 发货率、待发包裹、承运商表现、揽收效率
9. **关键风险与预警信号** - 3-5个关键风险及早期预警指标
10. **未来30天优先管理动作** - 可量化的管理行动建议

## 数据来源

综合调用财务大盘所有核心指标接口，包括：
- 财务核心指标 (income, expense, profit, ar_ap, wallet_balance等)
- 运营指标 (order_status, unconfirmed_orders)
- 供应链指标 (fulfillment, supply_chain, manager_indices)
- 销售维度 (sales_channels, sales_by_staff, sales_by_market)
- 价格指标 (price_trend, price_alerts)
- 库存指标 (inventory)

## 调用方式

```
生成AI财务分析报告
生成经营分析报告（英文）
```

支持流式输出和分章节生成，缓存策略为12小时。
