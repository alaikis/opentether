# 财务数据大盘运营指标

本技能提供财务数据大盘运营指标的查询和分析能力，关注订单履约和运营效率。

## 核心数据范围

- **订单状态分布**: 各状态订单数量统计
- **待确认订单**: 待确认订单数量、涉及金额、环比变化
- **今日运营**: 今日开单数、今日订单数

## 数据来源

- `order` 表 - 订单数据
- `order_status` 相关枚举

## 查询示例

```
查询待确认订单数量
查询今日订单数
查询订单状态分布
```

## 权限说明

- 员工: 可查看本人相关数据
- 管理层: 可查看全公司数据
