# 财务数据大盘供应链指标

本技能提供财务数据大盘供应链指标的查询和分析能力，关注采购、库存和履约效率。

## 核心数据范围

- **采购暴露**: 待处理采购金额、与月度收入对比
- **库存价值**: 库存总数量、库存总价值、SKU数量、可用数量
- **供应链指标**: 销售收入、销售毛利、库销比
- **履约配送**: 总包裹数、已发包裹数、待发包裹数、发货率
- **揽收任务**: 揽收任务数、已揽收数、待揽收数、揽收率
- **成本流向**: 采购入库成本、库存余额成本、销售出库成本

## 数据来源

- `purchase_item` 表 - 采购明细
- `purchase` 表 - 采购单
- `inventory_cost_log` 表 - 库存成本日志
- `order` 表 - 订单数据
- `order_sales_profit` 表 - 订单利润

## 查询示例

```
查询库存总价值
查询本月采购待处理金额
查询发货率
查询揽收完成率
查询库销比
```

## 权限说明

- 员工: 可查看本人相关数据
- 管理层: 可查看全公司数据
- 仓储: 可查看详细库存和履约数据
